# Controlled Transfer scope

## M0 question

Controlled Transfer measures whether a frozen Agent modification preserves its
task-native Performance advantage over an unmodified Base under predeclared changes
in scale, structural domain, and their joint conditions.

Scale and structural changes are two reporting views of this metric, not independent
metrics.

## Boundary

Controlled Transfer does not compare solvers or tasks with one another. It does not
redefine existing Performance protocols or the coverage-first classification of exact
Performance.
